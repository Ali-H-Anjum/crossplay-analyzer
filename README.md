Python implementation of Crossplay word game engine, built as a foundation for exploring AI techniques and behavior.

The game engine is complete, currently game_runner runs an entire simulated game from start to finish where each player selects the move with the highest score until the game ends.

There is a lot of changes to be made structurally and to make move generation more efficient but for now am focusing on designing a minimax-H utilizing the engine in its current state.

I used the research papers to help design my move generation algorithm utilizing a GADDAG data structure
